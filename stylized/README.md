# 广州美术学院 · 人类消失后第 50 年（风格化版本）

原项目（仓库根目录）的一份完整拷贝，场景内容不变，画面改成手绘 / 卡通渲染风格：明快的配色、带色相的阴影、团块状的树冠、成片的野花和卡通云。原项目的文件一个都没有改动。

![hero](shots/hero.png)

## 运行

依赖与原项目相同（`three` + `vite`）。可以直接复用根目录已安装的 `node_modules`，也可以在本目录单独安装：

```bash
cd stylized
npm install   # 可选：根目录已经 npm install 过就能跳过
npm run dev
```

打开终端里显示的地址。生产构建：`npm run build`，产物在 `stylized/dist/`。

操作与原项目一致：拖动环视 · 滚轮推拉 · 右键平移 · `C` 自动巡游 · `H` 隐藏界面

## 和原项目的区别

| 方面 | 原项目（写实） | 风格化版本 |
| --- | --- | --- |
| 光照模型 | `MeshStandardMaterial` PBR + IBL | Lambert 改写的卡通光照：两段式明暗、笔触噪声扰动的明暗交界、天空蓝紫 / 地面暖色的半球环境光、边缘光、硬高光 |
| 表面材质 | 风化：油漆剥落、锈、水渍、苔藓 | 手绘：噪声量化成柔和色块和笔触；油漆剥落少而大、边缘一圈浅色；苔藓是硬边的亮绿色块 |
| 配色 | 灰旧混凝土、褪色橙 | 奶油色混凝土、亮橙栏板、青绿色窗框、淡紫色室内、浅天蓝玻璃 |
| 地面 | 花岗岩地砖、泥土 | 圆角石板（每块带冷暖色差）、缺砖处露出草地；泥地改为色块草坪 |
| 植被 | 写实叶片贴图 | 大片平涂叶子 + 球面法线的团块明暗；每棵树一种颜色；凤凰木（红）、三角梅（粉）点缀；草叶加宽、根部深蓝绿到叶尖暖黄绿 |
| 野花 | 无 | 新增紫色花穗、白色雏菊、黄色小花，成片长在草地、挡土墙脚、花池和树池里 |
| 体块 | 直角盒子 | 厚度 ≥ 10cm 的盒子都倒圆角（`RoundedBoxGeometry`），更“胖”更柔和 |
| 天空 | 写实渐变 + 积云 | 饱和蓝渐变 + 硬边卡通积云（Worley 团块，迎光亮边、背光淡紫） |
| 后期 | 体积光、高度雾、ACES、暗角、颗粒、色差 | 蓝紫色调的 AO、浅蓝空气透视、深度描边、轻泛光、Khronos Neutral 色调映射 + 自然饱和度，无颗粒和色差 |
| 界面 | 衬线体、暗色加载页 | 圆润无衬线粗体、晴空加载页、胶囊按键 |

## 主要改动的文件

| 文件 | 内容 |
| --- | --- |
| `src/materials.js` | `toon()` 卡通材质、`painted()` 手绘材质、`foliage()` 卡通植被、卡通玻璃 |
| `src/post.js` | AO → 合成（AO 着色 + 描边 + 空气透视）→ 泛光 → 调色 |
| `src/sky.js` | 卡通天空与云 |
| `src/textures.js` | 平涂叶簇 / 藤叶 / 蕨 / 落叶、剪影树线 |
| `src/vegetation.js` | 植被配色、草叶几何、凤凰木 / 三角梅、野花 |
| `src/utils.js` | `Batch` 里的盒子自动倒圆角 |
| `src/main.js` | 调色盘、太阳方向与强度、后期参数 |
| `src/props.js` · `src/life.js` | 黄铜校名字、鸟、蝴蝶、花粉改用卡通材质 |
| `index.html` · `src/style.css` | 加载页与 HUD 样式 |

布局、建筑、榕树生成（`layout.js`、`building.js`、`banyan.js`）与原项目相同。

开发服务器下可在控制台调用 `__shot('name', 1920, 1080)`，把当前视角渲染成 PNG 存到 `stylized/shots/`。
